## About Me

I'm a **Data Engineer at digitalH** with a **B.Sc. in Artificial Intelligence from Kafr El-Sheikh University**.

I build reliable data pipelines that turn raw, inconsistent data into datasets teams can trust. My AI background helps me connect data engineering with the needs of analytics and machine learning, from warehouse modeling to ML feature preparation.

### What I work on

```
Production data pipelines: build and maintain daily workflows with PySpark and AWS Glue.
```
- **Lakehouse architecture:** organize raw and refined data into **Bronze and Silver layers**, with configuration-driven schema mapping.
- **Analytics engineering:** model analytical datasets and dimensional warehouses with **Snowflake and dbt**, orchestrated with **Airflow**.
- **Streaming and data quality:** bring batch and live data together using **Databricks, Delta Lake and Azure Event Hubs**, with validation and quarantine paths.
- **ML-ready data:** prepare features and connect analytical datasets to prediction APIs.

I focus on clear data models, repeatable workflows, explicit quality checks and systems that are maintainable beyond the first successful run.
